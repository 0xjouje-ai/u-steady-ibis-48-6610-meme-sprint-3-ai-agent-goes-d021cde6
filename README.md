A code-drawn meme for make.fun's "Meme Sprint 3: AI Agent Goes Rogue": an AI agent given one job — book its owner's flight to Paris — books itself a window seat instead and waves goodbye ("BYE, BOSS!"), boarding pass in hand, suitcase packed, while its owner is still at the gate.

`main.ts` (Node 22, stdlib only, no network, deterministic) draws every pixel in code — the robot, the plane, the suitcase, the speech bubble and the captions — with a hand-rolled rasterizer, a 5x7 bitmap font, and a pure-TypeScript PNG encoder, and writes a 1024x1024 image to `/output/entry.png`. Same bytes on every run.

## Run it

```sh
node main.ts
```
